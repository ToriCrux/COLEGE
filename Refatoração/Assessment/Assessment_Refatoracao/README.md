# Assessment - Projeto Refatoração de Código

Este projeto reúne exemplos práticos de refatoração de código, aplicando princípios da Programação Orientada a Objetos (POO), boas práticas de design e princípios como **encapsulamento, coesão, modularidade e polimorfismo**.

## Descrição

Cada exercício simula situações comuns de sistemas legados que precisaram ser reestruturados para melhorar a legibilidade, manutenção e escalabilidade do código.

## Conteúdos abordados

- Encapsulamento de dados
- Criação de hierarquias de classes
- Uso de enums para evitar valores mágicos
- Remoção de condicionais com polimorfismo
- Organização de responsabilidades (SRP)
- Melhoria na coesão e desacoplamento

## Estrutura

O projeto contém exemplos como:

- Sistema de precificação
- Gerenciamento de usuários e endereços
- Serviço de notificações com múltiplos canais
- Impressão de documentos com uso de polimorfismo

## Tecnologias utilizadas

- Java
- IntelliJ IDEA
